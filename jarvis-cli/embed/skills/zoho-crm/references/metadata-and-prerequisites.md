# Runtime metadata and prerequisites

The static catalogs recognize standard display and API names only. Authenticated runtime metadata is authoritative for permissions, module and field availability, layouts, relationships, required/read-only fields, picklists, operation support, quotas, and organization policy.

Before generation, obtain only the missing API names, record IDs, layout or relation IDs, event mapping, trigger intent, job lifecycle facts, and connection scopes that change the selected operation. Never treat a catalog match as proof that the target organization supports an operation.
