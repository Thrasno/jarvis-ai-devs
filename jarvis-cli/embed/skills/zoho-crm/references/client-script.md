# CRM Client Script

Client Script is browser-side JavaScript. It loads `zoho-crm`, emits `[name].js`, and MUST NOT load `zoho-deluge`.

Require the target module, layout, page, event or command, and documented event mapping before generating code. Prefer declarative validation or layout behavior when sufficient, but do not block requested custom work. Do not infer Quick Create behavior, implicit custom-button arguments, ZDK methods, event arguments, cancellation returns, or edition availability.
