# Uncertainty and safe exclusions

Ask only missing facts that change routing or prevent safe generation. Use and explain one valid path when it remains; when paths are equally optimal, recommend one and wait for selection.

Never request secrets. Do not guess or generate schedule arguments, implicit custom-button arguments, validation signatures or returns, Quick Create behavior, Function API endpoint templates, non-CRM applications, task names, response wrappers, API names, IDs, scopes, limits, plans, ZDK methods, events, or placements without approved evidence.

When a fact is excluded, identify the exclusion and offer a safe clarification, target configuration, or verified alternative.
