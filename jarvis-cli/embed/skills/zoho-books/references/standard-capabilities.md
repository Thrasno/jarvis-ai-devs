# Standard Zoho Books capabilities

Use this recognition-only 20-family taxonomy before custom code. The check is advisory and non-blocking for an explicit code request. `full`, `partial`, and `hybrid` describe bounded evidence; `none_verified` and `TBD` remain valid conservative outcomes. Runtime plan, region, permissions, settings, providers, and organization configuration are authoritative.

| Intent family | Recognition boundary |
|---|---|
| `transaction-lifecycles` | Native sales and purchase transactions and configured lifecycle actions. |
| `recurring-invoices` | Native recurring profiles. |
| `reminders` | Native payment reminders. |
| `transaction-approvals` | Simple, multi-level, and custom approvals. |
| `workflow-rules-and-actions` | Native triggers/actions; functions and webhooks are hybrid. |
| `fields-and-validation` | Typed fields and supported validation rules. |
| `views-locking-and-buttons` | Views and locking are native; custom buttons are hybrid. |
| `custom-modules` | Modules, blueprints, layouts, and portal exposure are partial. |
| `pdf-and-email-templates` | Native presentation is partial; external rendering is separate. |
| `documents` | Books-native document management. |
| `banking-and-reconciliation` | Runtime provider and region decide feeds and availability. |
| `taxes-and-compliance` | Country-specific settings and rules; never generalize editions. |
| `currencies` | Native currencies and base-currency adjustments. |
| `customer-and-vendor-portals` | Configured portal behavior. |
| `reports` | Built-in/custom reports and exports. |
| `books-projects-and-time-tracking` | Books-native projects, timesheets, and approvals. |
| `users-and-roles` | Runtime roles and permissions decide access. |
| `integrations-and-online-payments` | Product, gateway, country, and organization specific. |
| `import-export-and-backup` | Native manual/batch movement. |
| `extensions-and-widgets` | Verified custom developer surfaces, distinct from REST/tasks. |
