The sole resource/schema source is `https://www.zoho.com/books/api/v3/openapi-all.zip`, re-downloaded on 2026-08-31 and verified as SHA-256 `c6a841bbc81ef882c64b1f2ad4761e350faefba1db7fb36a32daf7112b647559` before extraction. Resource identity is the stable file-local key `(snapshot hash, source YAML filename)`; the shorter identity shown below is the filename stem. Official display titles come only from each file's `info.title`.

Counts use these deterministic rules: operations are HTTP method objects under `paths`; distinct paths are unique path templates per file; identifiers are literal `{name}` placeholders observed in those paths; OAuth scope families remove only a terminal `.READ`, `.CREATE`, `.UPDATE`, `.DELETE`, or `.ALL`; request schema counts are distinct request-body roots and response schema counts are distinct response-content roots. Parameter roots are fully included in the field catalog but not folded into the resource request-body count. Lifecycle/action counts reuse the matching rows already classified in the [REST operation catalog](zoho-books-rest-v3.md), whose identities were checked against this same archive; they are a routing classification, not an inferred resource relationship.

Static recognition never overrides runtime organization metadata, settings, plan, region, permissions, or configured providers. Tenant-defined custom field metadata/values and organization-specific values are excluded; standard OpenAPI resource groups and envelope properties remain. Absence from this snapshot does not prove runtime non-support. Updates occur only after an explicit maintainer decision; no generator or scheduler is stored in the repository.
