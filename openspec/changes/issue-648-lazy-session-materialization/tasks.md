## Execution Rules

- Strict TDD is required: record a genuinely failing RED test before each GREEN change; then triangulate boundary/concurrency/error variants and REFACTOR only with tests green.
- Each numbered slice is one stacked-to-main PR and one Conventional-Commit work unit. Rebase/retarget its clean branch to `main` only after its predecessor merges. Include its predecessor, start/end boundary, exclusions, verification, rollback, actual additions+deletions, and a chain diagram marking that PR with `📍` in its PR description.
- The actual-diff gate is mandatory before the next slice: from the clean PR branch, calculate additions plus deletions against its merge-base with `git diff --numstat "$(git merge-base origin/main HEAD)"...HEAD | awk '{a+=$1; d+=$2} END {print a+d}'`. If the result is **>=400**, stop; do not compress tests/code or reshuffle slices, and request a maintainer decision. No `size:exception` is authorized.
- Run commands from their named module only; never run a root workspace command or a build. Use `gofmt` on edited Go files. PostgreSQL/Node-dependent tests must report an explicit `-short` or environment skip rather than being treated as passed.
